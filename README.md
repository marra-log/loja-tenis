# Loja de tênis

Vitrine, carrinho, categorias, blog e painel.

## Páginas

- `/estilo` e `/marca`: categoria com subcategorias
- `/lancamentos`, `/mais-vendidos`, `/promocoes`
- `/blog`
- `/carrinho` grava no navegador
- `/admin` gerencia produtos, categorias, vitrines e blog

A gestão ainda persiste no navegador. O banco entra quando o Postgres estiver ligado.

## Rodar

```bash
npm install
npm run dev
```
